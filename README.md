**Technologies:** React.js, Node.js, Express.js, MongoDB, Transformers.js, Groq API

An end-to-end document question-answering application that retrieves relevant information from uploaded PDFs and generates context-aware answers.

- Built a document processing pipeline with text extraction and overlapping chunking.
- Integrated `Xenova/all-MiniLM-L6-v2` for 384-dimensional text embeddings.
